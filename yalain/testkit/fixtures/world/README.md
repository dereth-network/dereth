# A test world database

A small world database written by hand for the tests of the world database's reader, checks,
merge, compile and release (`yalain-world-db`): a town pack with a storekeeper, a portal and the
place it leads to, a camp, a loot profile, a store listing, a quest with three steps (one a held
item used on an object, one made on arrival) and two lines the storekeeper says, and a second pack
that moves the camp (it wins by an override) and takes a sign away. Every row is authored; the ids
are the final retail client's, but nothing here is read from it.
