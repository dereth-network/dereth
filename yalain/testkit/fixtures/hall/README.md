# The test hall

The small world the server's session tests play (`yalain-testkit`'s `session`, the `dat` and
`live` tiers), written as a world database: in the human training hall's copy `0x0298`, the
shelter's guard (who has one line for a player that uses him), a camp of one sentinel beside the
start whose loot is a sword, and the hall's exit shard with the town it leads to. The places are
authored close together, so a session reaches each in a few seconds; the ids are the final retail
client's, and the server compiles the world against the install as it compiles any database.
