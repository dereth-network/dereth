# Deliberate divergences from the retail servers

Yalain rebuilds the Asheron's Call 2 servers from their recorded sessions, which end in January 2017, and this is the list of places where it deliberately behaves differently. Each row is a choice, of one of three kinds:

- **differs**: the recordings show what the servers did, and Yalain does otherwise;
- **unrecorded**: no recording shows what the servers did, so what Yalain does is its own choice, listed so it is not taken for retail;
- **unmodeled**: the recordings show something too seldom, and for no cause they show, to model, so Yalain leaves it out.

Defects and features not yet built are not listed, and neither is anything Yalain reproduces from the recordings on purpose, however odd, nor anything the original servers never had. The code names a row by its id, `YD-` and a short name. The client's own list is [`auberean/testkit/src/divergences.rs`](../auberean/testkit/src/divergences.rs).

Each row names the behavior-registry rows whose tests assert what Yalain does, as a test path whose last parts can be passed to `cargo test` as a filter.

This file is generated from the register in `auberean-testkit` (`src/server_divergences.rs`) and the registry rows it names; edit those, not this file, and rewrite it with `AUBEREAN_TEST_REWRITE=1 cargo test -p auberean-testkit --test cpu server_divergences`.
